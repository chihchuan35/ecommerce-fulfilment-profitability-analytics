## Project Overview

This is a business analytics portfolio project focused on e-commerce fulfilment reliability, customer satisfaction, seller performance, regional delivery issues, and freight-related profitability pressure.

The project uses the Olist Brazilian E-Commerce Public Dataset and follows a lightweight ELT-oriented analytics workflow.

```text
Business Problem
→ Data Source
→ Extract
→ Raw Validation
→ Fabric Staging
→ Silver Transformation
→ Data Quality
→ Gold Model
→ Power BI
→ Insights and Recommendations
```
